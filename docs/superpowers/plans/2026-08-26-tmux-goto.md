# tmux-goto Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `prefix + u` opens one picker over sessions, windows and panes together, and selecting a row goes there.

**Architecture:** One bash script, `bin/tmux-goto`, run in `display-popup`. Pure row-building separated from tmux I/O so it is fixture-testable, with a library-mode guard (`TMUX_GOTO_LIB=1`) that defines functions without running `main`. Rows are `TARGET \t TAG DETAIL`; fzf displays from field 2 so the action always has an unambiguous target id.

**Tech Stack:** bash, fzf (already installed via tmux-fzf), tmux 3.5a.

**Spec:** `docs/superpowers/specs/2026-08-26-tmux-goto-design.md`
**Branch:** `tmux-goto`

---

## Conventions carried from the two sibling projects

These were learned the hard way; do not rediscover them.

1. **Any throwaway tmux server needs BOTH `-L <unique>` and `-f /dev/null`.** Without the second it sources the real config, pulls in tpm, and leaks an orphaned `tmux-autoreload` watcher.
2. **Never `tmux kill-server` without an explicit `-L`.** It kills the user's live session.
3. **`TMUX=` empty does NOT isolate** — tmux falls back to the default socket.
4. **`tmux` in this zsh is an oh-my-zsh function**; use `/usr/bin/tmux` in tests.
5. **`display-popup` does NOT format-expand `#{...}`** in its shell-command argument, unlike `run-shell`. tmux-goto needs no pane id, so a plain `display-popup` is fine — but do not add `#{...}` to that command line expecting expansion.
6. **A test that has never been seen failing is not a test.** Every task ends by breaking the behaviour and confirming the assertion catches it.

```
bin/tmux-goto            the picker: collect, format, choose, act
```

```bash
#!/usr/bin/env bash
# tmux-goto — one picker over sessions, windows and panes.
#
# Bound to prefix + u. Deliberately navigation-only: adding tmux's ~300 commands
# would bury the few dozen rows you actually want to reach. prefix + F keeps its
# nine tmux-fzf modes for the "do something" intent.
#
# Rows are "TARGET<TAB>TAG DETAIL" and fzf shows only from field 2, so the
# action always has an unambiguous %3 / @7 / session name to act on. Parsing a
# target back out of display text would break on window names containing spaces.
#
# Sourced with TMUX_GOTO_LIB=1 it defines its functions and exits, so the
# selftest can exercise the pure parts with no tmux server involved.
set -uo pipefail

rows_from_lists() { :; }
collect_rows() { :; }
act_on() { :; }
# TMUX_GOTO_MAIN_RAN is the selftest's only observable proof that the guard
# below actually skipped main. Keep it as main's first statement.
main() { TMUX_GOTO_MAIN_RAN=1; :; }

[ "${TMUX_GOTO_LIB:-}" = "1" ] || main "$@"
```

```bash
chmod +x bin/tmux-goto
```

### Task 2: rows_from_lists

**Files:** Modify `bin/tmux-goto`, Modify `bin/tmux-goto-selftest`

The three `tmux list-*` calls will be made with these formats, so the fixtures below match what tmux really emits:

- sessions: `-F '#{session_name}\t#{session_windows}'`
- windows:  `-F '#{window_id}\t#{session_name}\t#{window_index}\t#{window_name}\t#{@scout-state}'`
- panes:    `-F '#{pane_id}\t#{session_name}\t#{window_index}\t#{window_name}\t#{pane_current_command}'`

- [ ] **Step 1: Write the failing tests**

Append to `bin/tmux-goto-selftest`, before `exit "$FAILED"`:

```bash
echo "rows_from_lists"

SESS=$'main\t3\nother\t1'
WINS=$'@1\tmain\t1\thomedir\t\n@2\tmain\t2\totto-relay\twait\n@9\tother\t1\tmy project\t'
PANES=$'%1\tmain\t1\thomedir\tzsh\n%2\tmain\t2\totto-relay\tnode'

out=$(rows_from_lists "$SESS" "$WINS" "$PANES")

assert_eq "one row per input line" "7" "$(printf '%s\n' "$out" | wc -l)"

# Target must be field 1 so the action never has to parse display text.
assert_eq "session target is the name" "main" "$(printf '%s\n' "$out" | grep -m1 'sess' | cut -f1)"
assert_eq "window target is the id"    "@2"   "$(printf '%s\n' "$out" | grep -m1 'otto-relay' | cut -f1)"
assert_eq "pane target is the id"      "%2"   "$(printf '%s\n' "$out" | grep -m1 'node' | cut -f1)"

# Tags let a query be narrowed by typing "win" / "pane" / "sess".
printf '%s\n' "$out" | cut -f2 | grep -q '^\[sess\]' && pass "session rows tagged" || fail "session rows tagged" "[sess]" "$(printf '%s\n' "$out" | cut -f2 | head -1)"
printf '%s\n' "$out" | cut -f2 | grep -q '^\[win\]'  && pass "window rows tagged"  || fail "window rows tagged" "[win]" "$(printf '%s\n' "$out" | cut -f2 | head -3)"
printf '%s\n' "$out" | cut -f2 | grep -q '^\[pane\]' && pass "pane rows tagged"    || fail "pane rows tagged" "[pane]" "$(printf '%s\n' "$out" | cut -f2 | tail -2)"

# The running command is what you actually recognise among worktree-named windows.
printf '%s\n' "$out" | grep -q 'node' && pass "pane rows show the command" || fail "pane rows show the command" "node" "$out"

# Scout state marks agents waiting on you; an unset state renders nothing, not "[]".
printf '%s\n' "$out" | grep -q 'wait' && pass "scout state shown when set" || fail "scout state shown when set" "wait" "$out"
printf '%s\n' "$out" | grep -q '\[\]' && fail "unset scout state renders nothing" "no empty brackets" "$out" || pass "unset scout state renders nothing"

# A window name with a space must survive intact.
printf '%s\n' "$out" | grep -q 'my project' && pass "spaces in names survive" || fail "spaces in names survive" "my project" "$out"
```

- [ ] **Step 3: Implement rows_from_lists**

Replace `rows_from_lists() { :; }` with:

```bash
# Three tmux list outputs -> "TARGET<TAB>TAG DETAIL" rows.
#
# Pure: it takes the text rather than calling tmux, so the whole shape is
# testable from fixtures without a server. Field 1 is the target because fzf
# is configured --with-nth=2.., so the id never has to be recovered from
# display text — which would break on the window names containing spaces that
# this repo's agent worktrees routinely produce.
rows_from_lists() {
    local sessions="${1:-}" windows="${2:-}" panes="${3:-}"
    local name count id sess idx wname state cmd

    while IFS=$'\t' read -r name count; do
        [ -n "$name" ] || continue
        printf '%s\t[sess] %s\t(%s windows)\n' "$name" "$name" "$count"
    done <<< "$sessions"

    while IFS=$'\t' read -r id sess idx wname state; do
        [ -n "$id" ] || continue
        # An unset @scout-state must render as nothing at all, not an empty
        # marker: a bracket with nothing in it reads as a state of its own.
        printf '%s\t[win]  %s:%s %s%s\n' "$id" "$sess" "$idx" "$wname" "${state:+  <$state>}"
    done <<< "$windows"

    while IFS=$'\t' read -r id sess idx wname cmd; do
        [ -n "$id" ] || continue
        printf '%s\t[pane] %s:%s %s  %s\n' "$id" "$sess" "$idx" "$wname" "$cmd"
    done <<< "$panes"
}
```

- [ ] **Step 3: Implement both**

Replace the two stubs with:

```bash
collect_rows() {
    rows_from_lists \
        "$(tmux list-sessions -F '#{session_name}'$'\t''#{session_windows}' 2>/dev/null)" \
        "$(tmux list-windows -a -F '#{window_id}'$'\t''#{session_name}'$'\t''#{window_index}'$'\t''#{window_name}'$'\t''#{@scout-state}' 2>/dev/null)" \
        "$(tmux list-panes -a -F '#{pane_id}'$'\t''#{session_name}'$'\t''#{window_index}'$'\t''#{window_name}'$'\t''#{pane_current_command}' 2>/dev/null)"
}

# The target is field 1 and its sigil says what it is: % pane, @ window,
# anything else a session name. Selecting a pane also selects its window, and
# switching sessions is what makes the row actually take you there.
act_on() {
    local row="${1:-}" target
    [ -n "$row" ] || return 0
    target=${row%%$'\t'*}
    [ -n "$target" ] || return 0

    case "$target" in
        %*) tmux select-window -t "$target"; tmux select-pane -t "$target" ;;
        @*) tmux select-window -t "$target" ;;
        *)  tmux switch-client -t "$target" ;;
    esac
}
```

Replace `main() { TMUX_GOTO_MAIN_RAN=1; :; }` with:

```bash
main() {
    TMUX_GOTO_MAIN_RAN=1
    if ! command -v fzf >/dev/null 2>&1; then
        printf 'tmux-goto: fzf is not installed\n' >&2
        exit 1
    fi
    local choice
    choice=$(collect_rows | fzf \
        --delimiter=$'\t' --with-nth=2.. \
        --prompt='go to > ' --height=100% --reverse --no-multi) || exit 0
    act_on "$choice"
}
```
